# QQ 聊天记录完整导出器

## 使用顺序

1. 先退出 QQ（包括托盘中的 QQ 进程），再双击 `QQ聊天记录完整导出器-最终版.exe`。
2. “原始数据库”选择 QQ 的 `nt_msg.db`。可以点击“扫描 nt_msg.db”，选择 QQ 数据目录搜索。
3. 确认 `QQ.exe` 和当前版本的 `wrapper.node` 路径。
4. 选择“处理目录”。程序会在这里生成：

   - `nt_msg.db`：原始数据库复制件
   - `nt_msg_clear.db`：去除 QQ 头部后的中间库
   - `nt_msg_plain.db`：解密后的 SQLite 数据库
   - `nt_msg_export.db`：整理后的可查询数据库

5. 点击“完整处理：解密并整理”。程序会自动：

   ```text
   找到/复制 nt_msg.db
       → 提取当前 QQ 版本数据库 key
       → SQLCipher 解密
       → 解析消息表和 protobuf 内容
       → 生成 nt_msg_export.db
   ```

6. 填写自己的 UID，选择好友会话。
7. 选择导出目录，点击“导出选中会话”，得到 `chat.txt` 和 `chat.html`。

## 重要说明

- 密钥提取脚本启动 QQ 后，若出现登录窗口，请登录目标账号并等待处理完成。
- 启动完整处理前先退出所有 QQ 进程；密钥提取脚本会启动/调试 QQ，若出现登录窗口，登录目标账号后等待处理继续。
- `wrapper.node` 要和当前 QQ 版本对应；QQ 更新后需要重新选择。
- 原始数据库只会被复制，程序不会直接修改 QQ 的原始文件。
- 数据库 key 只在当前进程内使用，不显示、不保存。
- 发布压缩包已经包含 `qqcli-rs\deps` 项目和 `uv.exe`，请保持压缩包内目录结构，不要只单独移动 EXE。
- 首次处理时 `uv` 可能需要联网下载 Python/依赖包；下载完成后会复用处理目录中的缓存。
- 目标电脑仍需安装 QQ NT 并登录目标账号；程序需要用户手动选择对应的 `QQ.exe`、`wrapper.node` 和 `nt_msg.db`。
